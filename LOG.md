# Registro de trabalho

Uma entrada por conversa de trabalho, da mais antiga para a mais recente. Não apague entradas anteriores. A skill `salvar` acrescenta a entrada ao terminar.

## Como é cada entrada

```markdown
### AAAA-MM-DD: assunto

- **Quem trabalhou:** nome da pessoa, com apoio de qual IA.
- **O que foi feito:** o trabalho, com links para os arquivos.
- **Resultado e pendências:** o que ficou decidido e o que falta confirmar.
- **Versão anterior (backup):** código da versão da base antes deste salvamento, com o link no GitHub. Serve para voltar atrás.
- **Fonte:** de onde vieram as informações.
```
