# Segundo cérebro para marcas de moda

Um modelo para guardar, em arquivos organizados, tudo o que a sua marca sabe sobre si mesma: quem ela é, como decide, como trabalha e o que já aprendeu. Os arquivos ficam no GitHub, só seus, e a IA lê e atualiza para trabalhar com o contexto certo.

**Por que arquivos?** Porque o conhecimento da marca fica com você, e não preso a uma ferramenta. Hoje você usa com o Claude. Amanhã pode levar a mesma pasta para o ChatGPT ou outra IA.

Criado pela [Influir Fashion Business](https://www.influir.com.br) para donos de marca e lideranças que têm acesso a todas as áreas da empresa.

## Como começar

1. Abra o botão verde **Use this template** no alto desta página e escolha **Create a new repository**.
2. Dê um nome à sua base e marque **Private**. **Confira que ficou privada antes de escrever qualquer coisa.**
3. Conecte o GitHub ao Claude e abra a sua base nele. Para o **Claude Code** montar e atualizar a base por você, é preciso um plano pago do Claude, a partir do Pro. Sem plano pago, siga o [caminho manual](como-usar-com-outras-ias.md). Confira os planos atuais em [claude.com/pricing](https://claude.com/pricing).
4. Escreva: *"Quero preparar o segundo cérebro da minha marca. Siga a skill comecar."*
5. Alimente o brain seguindo o [guia de como alimentar](como-alimentar-o-brain.md), uma diretriz por vez, começando pela identidade da sua marca.

O passo a passo com telas está no manual. *(Link do manual: a acrescentar.)*

## Cuidado com o que guarda

Esta base é para o contexto da marca. **Nunca guarde senhas, dados de cartão, CPF ou lista de clientes finais.** Mantenha o repositório sempre **privado**. Detalhes em [AGENTS.md](AGENTS.md).
