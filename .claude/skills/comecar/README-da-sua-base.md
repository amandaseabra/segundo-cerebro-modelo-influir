## Como continuar

- Alimente o brain **uma diretriz por vez**, seguindo o [guia de como alimentar](como-alimentar-o-brain.md).
- **Volte sempre que a marca mudar:** nova coleção, nova pessoa, nova meta. O brain só ajuda se estiver atual.
- Para levar o mesmo método a outra IA, veja [como-usar-com-outras-ias.md](como-usar-com-outras-ias.md).
- Enviou algo errado? Veja [como-voltar-atras.md](como-voltar-atras.md).

## Cuidados

Esta base **deve continuar Private**. Nunca guarde senhas, dados de cartão, CPF ou lista de clientes finais. Detalhes em [AGENTS.md](AGENTS.md).
